## Local preview

```bash
cd path/to/roverhol.github.io
quarto preview
```

## Deploy

Push to `main`. GitHub Actions builds with Quarto and deploys to Pages  
(**Settings → Pages → Source: GitHub Actions**).

Site themes live under `assets/css/` (Valley hub default; place themes on section pages). Planning notes and design refs are kept in a separate private repo, not here.
